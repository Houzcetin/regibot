## What failed and what was fixed

1. **Retrieval (real bot error, q17, q18).** English questions about the first two semesters and lateral transfer students never retrieved the Turkish-only Student Affairs passage ("ilk iki dönemde ... 30 AKTS", "yatay geçiş"), so the bot said it had no limit. Fix: English→Turkish query expansions in `lib/retrieval.js` (first two → ilk iki dönem; lateral / vertical / transfer → yatay / dikey geçiş; course load → ders yükü).
2. **Grader: Markdown hid a phrase (q11).** The correct answer wrote "**F** veya **U**"; the grader now strips `**` before matching.
3. **Grader: refusal wording (q15, q30).** Correct refusals ("belgelerde yok … söyleyemiyorum", "I can't tell you") were not in the phrase list. Added them, and later Turkish stems (yanıtlayamıyorum, cevaplayamıyorum, … bilgisi yok).
4. **Test question replaced (q14).** "When does the cafeteria open at weekends?" turned out to be partly answerable: the handbook lists the dorm dining-hall hours, and the bot gave that grounded partial answer. Replaced with an exam-room question that is genuinely not in the documents.
5. **Answer language (real bot error, q08).** In one run a Turkish question got an English answer (the facts were correct). Fix: each request now states the answer language, detected from what the student typed.
6. **Source cards (real bot error, q11 in run 3).** A correct, cited answer came back without cards because the model's `SOURCES:` line named `regulation-tr-m29` (the chunk is `regulation-tr-m29-1`). Fix: ids are matched by prefix, and every [citation] visible in the answer, including combined ones like [Yönetmelik, Madde 25; Yönetmelik, Madde 19], always gets its card.
7. **Handbook vs regulation (found by reading passing answers, q20).** A passing answer repeated the handbook's claim that a student who misses registration must wait until the next semester, which contradicts Madde 25/3 (see `data/conflicts.md`). Fix: the three known conflicts are in `data/conflicts.json`; when one of those handbook passages is retrieved, it is sent with a note giving the regulation's rule. Checked by hand: "Ders kaydımı süresinde yapmazsam ne olur?" now answers with Madde 25 and mentions the difference.

## Limits of this evaluation

- Grading is keyword-based: an answer passes when it contains the expected facts and cites an expected source. It cannot catch every wrong statement (fix 7 was found by reading answers, not by the grader).
- Answers vary between runs (the model is not deterministic). The final configuration (run 6) scored 30/30; run 5, before fix 7, also scored 30/30 but contained the handbook error described in fix 7.
- The 30 questions were written by the project team. They cover the most common registration topics, not every rule.
- Total API cost of all test runs: a few cents (Claude Haiku 5.5).
